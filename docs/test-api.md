# window.__game: ручки для проверок

Игра обязана выставить объект `window.__game`. Через него нейросеть сама играет (`tools/playtest.mjs`) и гоняет
сотни партий (`tools/simulate.mjs`). Игрок его не видит. Подходит для любой игры: волны, стройка, гонка, головоломка.

| Что | Зачем |
| --- | --- |
| `start()` | новая партия с самого начала: из меню, после проигрыша, откуда угодно. Старое сохранение не подхватывает |
| `setAuto(on)` | авто-игра: бот сам играет за игрока (ходит, добывает, строит, дерётся, выбирает) так, как играл бы человек |
| `setSpeed(k)` | ускорение игрового времени, 1 = обычно, должно работать до 50 |
| `state()` | `{ scene, time, ... }`: `scene` это экран (`'menu'`, `'play'`, `'pause'`, `'over'`, `'win'` и другие экраны игры), `time` в игровых секундах. Остальные поля: всё, по чему видно, как идёт партия (здоровье, ресурсы, волна, земля, день, сколько построено), только числами |
| `events` | массив событий `{ t, type, ... }`, `t` в игровых секундах. Обязательно `over` (проиграл, с полем `reason`) и `win` (победа), если они есть в игре. У событий выбора (улучшение, постройка, предмет) поле `name` |

Правила:
- Ускорение умножает шаг времени игры, а не пропускает кадры: при `setSpeed(20)` партия идёт в 20 раз быстрее и
  остаётся той же партией.
- В авто-режиме ни один экран не ждёт человека: бот сам жмёт «дальше», выбирает и пишет событие.
- Новые механики добавляют свои события, старые не меняют смысл.

## Поля и события этой игры
Заполняет нейросеть с первой версией и дописывает с каждой механикой: какие поля в `state()` и какие события.
Без этого списка ночная смена не поймёт, что считать.

- `state()`: `scene` (`menu`, `play`, `pause`, `win`, `over`), `time`, `step` (`intro`, `dance`, `cook`, `tv`, `watch`,
  `candle`), `mood` (0..100, шкала довольства), `tasksWon`, `tasksLost`, `hasKey`, `candleLit`, `screamers`, `x`, `z`,
  `ending` (`night`, `escape`, `fire`, `bad` или `null`), `endingsFound`, `mini` (1 = идёт мини-игра), `dialog`,
  `hasChoc`, `chase` (`warn`, `hunt`, `search`, `rest` или `null`), `chases`, `hidden`, `hides`, `zone` (`K`, `P`,
  `T1`, `T2`, `C`, `L`), `kx`, `kz` (где Кэфифи).
- События: `start` (`goal` — к какой концовке стремится бот), `auto`, `task` (`name`: новое задание), `use` (`name`:
  с чем взаимодействовал), `mini_start`, `task_win` / `task_lose` (`name`: `dance`, `cook`, `letters`), `tv_watch`,
  `screamer`, `key_found`, `candle_out`, `sleep`, `escape`, `chase_start`, `chase_hunt`, `chase_search`, `chase_rest`,
  `hide` (`name`), `unhide`, `chocolate_found`, `chocolate_given`, `caught`, `ending` (`name`), `win` (`name`: `night`, `escape`),
  `over` (`reason`: `fire`, `bad` — поймала в погоне).
- Бот: цель концовки выбирается по `CFG.bot.endings`, точность в мини-играх `CFG.bot.skill`.
