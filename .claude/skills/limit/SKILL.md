# Экономия лимита (limit)

## Сессии
- Одна задача = одна новая сессия. Старая переписка не нужна: всё важное лежит в `docs/game.md` и
  `docs/progress.md`. Задача длинная и сессия разрослась: допиши `docs/progress.md` и предложи новую сессию.
- В начале сессии читай только `AGENTS.md`, `docs/game.md`, `docs/progress.md` и нужный скилл.

## Чтение
- Сначала ищи (`grep`, `rg`), потом читай нужный кусок файла по строкам. Целиком файлы на тысячи строк не читай.
- Картинки игры не открывай по одной: список с размерами и подписями есть в `assets/sprites.js` и `assets/README.md`,
  общий вид в `preview.png`. Открывай картинку только когда важно, как она выглядит.
- `prompts.md` и `pervaya_versiya/` это примеры из ролика, не часть игры. Читай их только если нужно.
- Скриншоты проверки смотри выборочно: последний кадр каждого вида и кадры правленого места.

## Правки
- Правь точечно, не переписывай файл целиком ради пары строк.
- Не повторяй один и тот же неработающий подход: после второй неудачи откат (скилл checkpoint) и разбор причины.
- Проверки запускай короткими (`playtest --seconds 30`) для мелочей, длинные и ночную смену только для баланса.

## Ответы
- Коротко: что сделано, что проверено, что дальше. Без пересказа кода и длинных вступлений.
