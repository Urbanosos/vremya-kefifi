# Набор из ролика: игра с нейросетью с нуля

Папка, с которой нейросеть-агент работает так, как я рассказал в ролике: сначала черновик всей игры, потом доводка с
сохранениями и проверками.

## Как начать
1. Поставь Claude Code или Codex. Claude Code подхватит правила и скиллы сам, Codex читает правила из `AGENTS.md` и
   открывает скиллы по ссылкам оттуда. Для проверок нужны Node.js и Google Chrome.
2. Скопируй эту папку туда, где будет игра. Путь лучше без пробелов и без твоего имени. Агенту открывай только эту
   папку, не весь компьютер.
3. Положи в папку картинку-образец `look.png`: на что игра должна быть похожа. Свои картинки для игры, если есть, тоже сюда.
4. Открой папку в агенте и опиши игру целиком в паре фраз. Как было у меня: "Сделай браузерную игру про средневековье
   с зомби. Днём герой добывает дерево и камень, крафтит инструменты и строит деревню, а ночью отбивается от зомби.
   Картинки в папке игры, там же образец, как она должна выглядеть."
5. Дальше проси по одной вещи за раз, конкретно и с примером. Не "сделай врагов", а "добавь зомби, который идёт к
   герою, бьёт вблизи и ходит медленнее героя".
6. Идея большая или передумал посреди работы: напиши "задай мне вопросы и запиши мои ответы". Отвечай подробно,
   особенно про то, как игра должна выглядеть: густой лес, много мелких деталей, тёплый свет.
7. Сломалось: напиши "верни как было". Не починилось за две попытки: тоже проси вернуть рабочую версию.

## Что внутри
- `AGENTS.md` и `CLAUDE.md`: правила, которые агент читает перед каждой задачей. Дописывай их, когда он повторяет ошибку.
- `.claude/skills/`: шесть скиллов: допрос, сохранения, проверка, конвейер, ночная смена, экономия лимита.
- `docs/`: шаблон документа игры, ход работы, ручки для проверок, папки под конвейеры и отчёты по балансу.
- `tools/`: `playtest.mjs` (агент сам играет и делает скриншоты), `simulate.mjs` (сотни партий за ночь для баланса).
- `prompts.md`: все мои промпты из ролика по порядку, для игры из чата и для игры по системе.
- `pervaya_versiya/`: что нейросеть собрала из первого сообщения и одной просьбы "почини". Открой `index.html` двойным
  кликом и сравни со своей.

## Три правила, если запомнить только их
1. Первое сообщение: вся игра в паре фраз и картинка-образец. Дальше по одной задаче за раз.
2. Сохранения и проверки с первого дня, строгие правила, когда черновик готов.
3. Проверкам нейросети верь меньше, чем своим глазам: в игру играй сам.
